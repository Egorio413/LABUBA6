**Автор:** Абрамов Егор
**Группа:** КБ-251

## Описание
1. **Задание 1 (Рефлексия):** Создана кастомная аннотация `@Repeat`, которая принимает количество повторений. С помощью рефлексии (`setAccessible(true)`) программа находит приватные и защищенные методы в классе `MyClass` и вызывает их нужное количество раз.
2. **Задание 2 (Файловая система):** С помощью пакета `java.nio.file` создана иерархия директорий, выполнено копирование файлов, рекурсивный обход дерева (`Files.walk`) и каскадное удаление директории с использованием сортировки в обратном порядке.
